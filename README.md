# Odin Recipes

This project is a simple recipe website built as part of The Odin Project curriculum.

## Description
The website consists of a main landing page with links to a collection of recipes, including pancakes, scrambled eggs, and mac and cheese.

## Built With
* HTML5
* Git & GitHub

## What I Learned
* Setting up local project file structures
* Working with relative file paths for links and images
* Writing clean, semantic HTML lists, headings, and images
